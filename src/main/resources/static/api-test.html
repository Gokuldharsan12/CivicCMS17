🧪 API Test Console

Test all CivicCMS REST endpoints live. Login first to get a token for protected routes.

🔑 User Login POST /api/v1/auth/login

Get a JWT token. Use credentials from the database.

🔵 Social Login POST /api/v1/auth/social-login

Google or Phone login — finds or creates user automatically.

🤖 AI Analyze POST /api/ai/analyze

Core AI engine — detects category, urgency, duplicates.

🗺️ Heatmap Data GET /api/heatmap

Returns complaint count grouped by lat/lng for the heatmap.

📊 Complaint Stats GET /api/complaints/stats

Dashboard statistics: totals, by category, urgency breakdown.

📋 My Complaints GET /api/v1/complaints/mine

Lists complaints for the currently logged-in user. Requires token.

🔍 Track Complaint GET /api/v1/complaints/track/{id}

Public endpoint — track any complaint by ID.

🏢 Departments GET /api/v1/departments

Returns all registered departments for the routing system.
